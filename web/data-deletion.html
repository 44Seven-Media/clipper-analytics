Data Deletion

Clipper Network analytics · 44Seven Media

To delete the data Clipper Network holds about a connected account:

  1. Team admins: sign in, open Accounts, and click Remove next to the account. Its statistics, posts and access tokens are deleted immediately.
  2. Account owners: revoke the app's access in the platform's settings (Facebook: Settings → Business Integrations; TikTok: Settings → Security → Manage app permissions; Google: myaccount.google.com → Third-party connections; X: Settings → Security → Connected apps). The tool stops updating and its tokens no longer work. Then ask 44Seven Media to remove the stored statistics, which is done within 30 days.
